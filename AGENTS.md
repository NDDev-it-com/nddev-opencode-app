# nddev-opencode-app

This public repository contains the OpenCode runtime setup manager and public
contracts only. Keep private tests, benchmarks, and harness fixtures outside
this repository.

Use current OpenCode names and documented surfaces:

- `opencode.json`
- `plugins/`
- `skills/<name>/SKILL.md`
- `agents/<name>.md`

Do not introduce skeleton aliases, private harness paths, provider secrets, or
live user state into public artifacts.
