# OpenCode Native Surfaces

Use current OpenCode names and schema:

- `opencode.json` for configuration and permissions.
- `plugins/*.js` or `plugins/*.ts` for local plugin hooks.
- `skills/<name>/SKILL.md` for reusable task instructions.
- `agents/<name>.md` for native subagents.
- `commands/*.md` for slash-command prompt templates.

Do not invent an OpenCode marketplace format. OpenCode's documented extension
surfaces are local files, npm plugins, skills, agents, commands, tools, MCP,
and configuration.
